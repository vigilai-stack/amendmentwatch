How it works

  1. Extract claims from the answer.
  2. Check each claim as data against the clause in force (v3), then v1/v2 — a match in an old version is Superseded.
  3. Score every claim: Current, Superseded or Unknown — never guessed.
  4. Correct the answer using only clauses in force.
Current — matches v3 Superseded — matched an earlier version Unknown — not settled, human must confirm
